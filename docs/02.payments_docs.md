# 결제 모듈 프로젝트

## 프로젝트 개요

- 프로젝트 목표와 주요 기능에 대한 간략한 설명
주요 기능

카드 정보 등록 및 관리

결제 요청 및 처리

결제 내역 조회

결제 실패/성공 알림

예시: 이 결제 모듈은 카드를 등록하고 결제할 수 있게 도와주는 모달 컴포넌트입니다.

## 개발 환경

사용한 프레임워크, 라이브러리, 언어 등

테스트: Jest 28.0, React Testing Library

API 통신: Axios 0.27

버전 관리: Git, GitHub

예시: React 17.0, JavaScript ES6

## 설치 및 실행 방법

프로젝트를 로컬에서 실행하기 위한 설치 방법과 명령어

git clone
npm run build


예시:
```
npm install
npm start
```

## 컴포넌트 구조

주요 컴포넌트들의 구조와 역할

PaymentModal: 결제 프로세스를 담는 핵심 컨테이너, 카드 등록·결제·결과 표시까지의 흐름 관리

CardForm: 카드 정보 입력 및 유효성 검사 수행

## 테스트 방법

테스트 케이스 및 실행 방법

CardForm 유효성 검사 (카드 번호, 유효기간, CVC 형식 검증)

PaymentButton 클릭 시 API 호출 여부 확인

예시:
```
npm test
```

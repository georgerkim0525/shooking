## 📝 고객 요구사항 정리
고객은 페이지 간 이동 시에도 상품 정보와 금액이 일관되게 유지되길 원합니다.
상품 상세 페이지가 추가되고, 기존 메인·목록·장바구니가 자연스럽게 연동되어야 합니다.
재고와 가격은 항상 최신 상태로 동기화되어야 하며, 로그인 시 비회원 장바구니는 계정 장바구니와 병합됩니다.
에러가 발생하면 사용자가 쉽게 이해하고 복구할 수 있도록 안내가 제공되어야 합니다.
성능·안정성·보안·접근성 등 비기능 요구사항도 충족해야 하며, 특히 개인정보 보호와 모바일 성능 최적화가 강조됩니다.

## 📋 기능 목록
필수 기능으로는 라우팅 연동, 장바구니 담기·삭제·수량 변경, 무료배송 규칙, 상세 페이지 제공, 로그인 머지, 에러 처리가 있습니다.
권장 기능으로는 검색·필터·정렬, 쿠폰 적용, 스크롤 위치 복원, 재고/가격 실시간 동기화가 포함됩니다.
선택 기능으로는 최근 본 상품, 위시리스트, 추천 상품, 미니카트 드로어가 있습니다.
멀티샵, 해외배송 같은 특수 규칙은 이번 범위에서 제외됩니다.
이러한 기능들은 MoSCoW 기법을 통해 우선순위가 정리되어 개발 범위와 목표가 명확히 제시됩니다.

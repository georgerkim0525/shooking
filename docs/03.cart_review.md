# 장바구니 페이지 리뷰

## 고객사 요구사항
> 이메일에 작성된 요구 사항 외에 피그마 시안에 있는 세부적인 요구사항을 추가해주시면 됩니다.

상품 정보 표시: 썸네일, 상품명/옵션, 단가, 수량 변경, 소계

합계 영역: 상품 총액, 배송비, 할인/쿠폰, 최종 결제 금액 실시간 반영

배송비 규칙: 기본 배송비, ₩100,000 이상 무료배송 (문구/뱃지/알림)

쿠폰: 적용/해제, 유효성 검사(기간, 최소주문, 중복, 카테고리 제외)

삭제/비우기: 단일 항목 삭제, 전체 비우기(확인 모달)

결제 진입: 필수 항목 검증 후 주문/결제 페이지 이동

반응형: 모바일(≤375px)·태블릿·데스크탑 레이아웃

접근성: 키보드 포커스, 스크린리더 라벨, 라이브 업데이트 안내

## 요구사항에 따른 기능 동작 확인

> ... 세부적인 기능을 추가로 작성해주세요.

썸네일, 상품명, 옵션, 단가, 수량, 소계가 디자인과 동일하게 노출된다.

 수량 + / – / 직접입력 시 소계가 즉시 재계산된다.

 최소 1, 최대 재고 수량을 벗어나면 버튼 비활성/에러 메시지 노출.

 항목 삭제 시 확인 모달(문구/버튼 라벨)이 피그마와 동일.

 옵션 변경형 상품의 옵션 표기가 누락 없이 표준화.

# 시스템 아키텍처
> 시스템의 전체적인 구조와 각 컴포넌트가 어떻게 연동되는지를 도식화하여 설명합니다. 이전 문서에서 작성했던 내용이 있다면 링크를 정리해하셔도 좋습니다.


> 아키텍처 개요:

프론트엔드: React 기반, 사용자 인터페이스와 상태 관리

백엔드: Node.js (Express), 비즈니스 로직 처리

데이터베이스: PostgreSQL, 영속성 및 데이터 무결성 관리

인프라: Docker 기반 배포, CI/CD 파이프라인 연동

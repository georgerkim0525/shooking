# 쇼핑몰 연동

## 프로젝트 개요

- 프로젝트 목표와 주요 기능에 대한 간략한 설명
- 참여한 팀원

프로젝트 목표: 기존에 분리되어 있던 상품 목록, 장바구니, 결제, 상세 페이지를 자연스럽게 연동하여 사용자 경험(UX)을 향상시키는 것.

주요 기능:

상품 목록 → 상세 페이지 이동

상세 페이지 → 장바구니 담기

장바구니 → 결제 페이지 연동

전체 페이지 간 데이터 일관성 유지

## 개발 환경

사용한 프레임워크, 라이브러리, 언어 등

예시: React 17.0, JavaScript ES6

프레임워크: React 17.0

언어: JavaScript (ES6+)

상태 관리: Redux Toolkit

라우팅: React Router v6

## 프로젝트 구조
src/
 ┣ components/        # 공통 UI 컴포넌트 (Header, Footer, Button 등)
 ┣ pages/             # 페이지 단위 (Home, ProductDetail, Cart, Checkout)
 ┣ store/             # Redux 상태 관리 모듈
 ┣ hooks/             # 커스텀 훅 모음
 ┣ utils/             # 유틸 함수 (가격 계산, 포맷 등)
 ┣ App.js             # 라우팅 및 전체 앱 구조
 ┗ index.js           # 앱 진입점

## 주요 함수와 기능
addToCart(productId, quantity): 상품을 장바구니에 추가

removeFromCart(productId): 장바구니에서 상품 삭제

updateQuantity(productId, qty): 수량 변경 및 총 금액 갱신

calculateTotal(): 상품 총액 + 배송비 계산

checkout(): 결제 페이지로 데이터 전달

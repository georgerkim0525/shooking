# 상품 목록 페이지 리뷰

## 고객사 요구사항
> 이메일에 작성된 요구 사항 외에 피그마 시안에 있는 세부적인 요구사항을 추가해주시면 됩니다.

1. 상품 목록은 카테고리별 정렬이 가능해야 함
2. 썸네일, 상품명, 가격은 목록에 기본 노출되어야 함
3. 품절 상품은 ‘SOLD OUT’ 뱃지가 노출되어야 함
4. 모바일 대응 필수 (반응형 웹)

## 요구사항에 따른 기능 동작 확인

### 1. 모바일 환경 구성
반응형 UI 정상 작동, 버튼 클릭 및 상품 목록 스크롤 원활

다크모드에서도 레이아웃 깨짐 없이 잘 표시됨

### 2. 신발 상품 사진
신발 카테고리 상품들에 이미지 누락 없음 확인

마우스 오버 시 이미지 확대 및 장바구니 버튼 정상 표시됨
### 3. 장바구니 담기 기능
각 상품의 장바구니 버튼 클릭 시, 선택한 상품이 장바구니에 정상적으로 추가됨

중복 클릭 시 수량 증가 방식 적용
### 4. 배포 URL
테스트 완료된 실서버 배포 URL:docs/01.products_docs.md

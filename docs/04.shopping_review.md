# 쇼핑몰 연동 리뷰

## 고객사 요구사항
> 이메일에 작성된 요구 사항 외에 피그마 시안에 있는 세부적인 요구사항을 추가해주시면 됩니다.
상품 목록 → 상세 페이지 → 장바구니 → 결제까지 자연스러운 페이지 연동

페이지 이동 시에도 데이터 일관성 유지 (예: 장바구니에 담긴 상품 수량이 Home/Cart 모두 동일하게 표시)

장바구니 실시간 업데이트: 수량 변경 시 금액 자동 반영
## 요구사항에 따른 기능 동작 확인

> ... 세부적인 기능을 추가로 작성해주세요.
상품 목록 → 상세 이동

클릭 시 해당 상품의 상세 페이지 정상 이동 확인

hover 애니메이션 동작 정상

장바구니 기능

“담기” 버튼 클릭 시 장바구니에 정상적으로 반영됨

수량 증감 버튼 클릭 시 실시간 합계 금액 업데이트 확인

삭제 버튼 클릭 시 장바구니에서 정상적으로 제거됨

배송비 정책 확인

100,000원 미만 구매 시 기본 배송비 표시됨

100,000원 이상 구매 시 무료 배송으로 자동 변경됨

결제 페이지

장바구니 데이터가 정상적으로 전달됨

할인 코드 입력 → 적용 결과(금액 변경)가 실시간 반영됨

외부 결제 모듈 API 호출 정상

모바일 반응형 UI

375px ~ 768px 구간에서 레이아웃 정상적으로 재배치

상품 카드 1열 → 2열 전환 확인

## 📝 고객 요구사항 정리
상품 정보 표시

개별 상품명, 단가, 수량, 소계 표시

총 금액 계산

상품 총액 + 배송비 + 최종 결제 금액 표시

배송비 규칙

기본 배송비 적용

10만 원 이상 구매 시 배송비 무료 (명확하게 표시)

실시간 금액 반영

수량 변경, 상품 삭제 시 즉시 합계 및 배송비 재계산

금액 정확성

원 단위까지 정확하게 계산·표시

UI/UX 요구사항

한 화면에서 가격·총액·배송비 확인 가능

무료배송 조건 충족 시 "무료" 표시 및 조건 안내

여러 상품 비교·결정 용이한 레이아웃 구성

테스트 & 검수

개발 중간에 테스트 URL 제공

영업팀이 실사용 시나리오 기반으로 리뷰 진행

일정

예상 작업 기간: 2주

디자인 시안 전달 후 개발 착수


## 📋 기능 목록

장바구니 UI
장바구니 목록 표시

개별 상품 카드 (상품명, 이미지, 단가, 수량, 소계)

전체 합계 영역 (상품 총액, 배송비, 최종 결제 금액)

2. 장바구니 기능
수량 변경 (+/- 버튼 또는 직접 입력)

상품 삭제

배송비 계산 (기본 / 무료 조건 적용)

금액 실시간 업데이트

금액 포맷(₩ 원 단위)

3. UX 개선 기능
무료배송 조건 안내 문구

배송비 무료 조건 충족 시 시각적 강조 (색상 또는 배지)

모바일/PC 반응형 UI

4. 테스트 및 검수 지원
테스트 URL 제공

주요 시나리오 테스트 (상품 추가/삭제, 배송비 조건 변화)

브라우저 호환성 점검 (Chrome, Edge, Safari)

# 장바구니 프로젝트

## 프로젝트 개요

- 프로젝트 목표와 주요 기능에 대한 간략한 설명
사용자가 선택한 상품을 한눈에 확인하고, 총액·배송비·최종 결제 금액을 실시간으로 확인할 수 있는 장바구니 페이지를 구현한다.

상품별 정보 표시 (상품명, 단가, 수량, 소계)

총액 및 배송비 규칙 적용 (예: 10만 원 이상 구매 시 배송비 무료)

수량 변경 시 즉시 반영되는 실시간 계산 기능 제공


## 개발 환경

사용한 프레임워크, 라이브러리, 언어 등

예시: React 17.0, JavaScript ES6

프레임워크 : React 17.0

## 유의사항 및 알려진 이슈

버그, 해결하지 못한 문제, 추가하고 싶은 기능 등

금액 계산 정밀도: 부동소수점 오차 방지를 위해 모든 금액은 정수(원 단위) 로 계산 후 마지막에 포맷팅하세요.

상태 동기화: E2E 환경에서 로컬 상태와 API 동기화 타이밍으로 인한 깜빡임이 있을 수 있어 loading 상태를 명시적으로 처리하세요.

접근성(A11y): 버튼에 aria-label, 합계 영역에 적절한 역할(Role)과 라이브 리전(aria-live=polite) 사용을 권장합니다.

성능: 대량 항목(예: 100개) 렌더링 시 메모이제이션(useMemo, React.memo)과 키 안정성 보장.

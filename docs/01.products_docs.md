# 상품 목록 페이지 프로젝트

## 프로젝트 개요

- 프로젝트 목표와 주요 기능에 대한 간략한 설명
- 참여한 팀원

상품 리스트 조회 및 정렬(인기순, 신상품순, 가격순 등)

썸네일, 상품명, 가격, 할인율 등의 정보 표시

품절 상품 'SOLD OUT' 뱃지 처리

마우스 오버 시 장바구니 담기 버튼 노출

기획: 정기획

디자인: 김디자이너

프론트엔드 개발: 이프론트

## 개발 환경

사용한 프레임워크, 라이브러리, 언어 등

React 17.0

JavaScript (ES6+)

HTML5 / CSS3

## 설치 및 실행 방법

프로젝트를 로컬에서 실행하기 위한 설치 방법과 명령어


```
npm install
npm start
```

## 컴포넌트 구조

주요 컴포넌트들의 구조와 역할

CategoryFilter
카테고리별로 상품을 필터링할 수 있는 선택 UI를 제공합니다.

SortOptions
인기순, 신상품순, 가격순 등 정렬 기준을 선택할 수 있습니다.

Pagination
상품 리스트의 페이지네이션을 담당합니다. 페이지 이동 시 ProductList를 갱신합니다.

## 유의사항 및 알려진 이슈

버그, 해결하지 못한 문제, 추가하고 싶은 기능 등

Safari 브라우저에서 접속 시, 폰트가 다르게 보이는 문제가 발생합니다. (렌더링 엔진 차이로 인한 이슈)

모바일 환경에서 버튼 클릭 시 이중 동작이 발생하는 경우가 있습니다.

다크모드 전환 시, 일부 컴포넌트의 배경색이 초기화되지 않음.

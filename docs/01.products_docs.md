# 상품 목록 페이지 프로젝트

## 프로젝트 개요

- 상품 리스트 조회: 서버로부터 상품 데이터를 받아와 목록 형태로 표시

- 카테고리별 필터링: 사용자 선택에 따라 상품을 카테고리별로 분류

- 검색 기능: 키워드 기반의 상품 검색


## 개발 환경

 React 17.0, UI/UX 

## 설치 및 실행 방법

프로젝트를 로컬에서 실행하기 위한 설치 방법과 명령어


```
Node.js 

npm 또는 yarn

Git 

2. 프로젝트 클
```

## 컴포넌트 구조

주요 컴포넌트들의 구조와 역할



- `ProductList`: 상품 목록을 보여줍니다.
- `ProductCard`: 각 상품의 정보를 보여줍니다.
- CategoryFilter.jsx  : 카테고리 필터
- SortOptions.jsx     : 정렬 옵션 선택

## 테스트 방법

테스트 케이스 및 실행 방법

```
cd client
npm test
```

## 유의사항 및 알려진 이슈

버그, 해결하지 못한 문제, 추가하고 싶은 기능 등

모바일 환경에서 버튼 클릭 시 이중 동작이 발생하는 경우가 있습니다.

다크모드 전환 시, 일부 컴포넌트의 배경색이 초기화되지 않음.
